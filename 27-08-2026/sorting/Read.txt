1. Selection sort :  Select the minimum and swap

eg : 
0   1   2   3   4   5 --> index
13, 46, 24, 52, 20, 9 --> array
Select the minimum in arrray from i=0 to n that is 9 and swap with a[i] where i = 0,1,2,3,4,5
swap(9,13) -> array becomes 
9, 46, 24, 52, 20, 13
now find minimum from i = 1 to n that is 13
swap(46,13) -> array becomes
9, 13, 24, 52, 20, 46
now find the minimum from i = 2 to n that is 20
swap(24,20) -> array becomes
9, 13, 20, 52, 24, 46
now find the minimum from i = 3 to n that is 24
swap(52,24)-> array becomes
9, 13, 20, 24, 52, 46
now find the minimum from i = 4 to n that is 46
swap(52,46) -> array becomes
9, 13, 20, 24, 46, 52


2. Bubble sort : push the maximum number to the last by adjacent swaps

13, 46, 24, 52, 20, 9 
check which is greater (13, 46) -> 46 , array becomes as it is
13, 46, 24, 52, 20, 9 
check which is greater (46,24) -> 36, array becomes
13, 24, 46, 52, 20, 9
check which is greater (46, 52) -> 52 , array becomes as it is
13, 24, 46, 52, 20, 9
check which is greater (52, 20) -> 52 , array becomes 
13, 24, 46, 20, 52, 9
check which is greater (52, 9) -> 52 , array becomes
13, 24, 46, 20, 9, 52

Power of Observation :
here you can see in one iteration maximum number it pushed to last by adjacent swaps
and we repeat the same till 13 to 9 as 52 is already sorted and similarly we repeat the same process


3. Insertion sort : Takes an element and place it in its correct order

we will go linear in an array , like we take an element check with previous index's elements if greater swap so, the
smallest number will move to first index right !!!
